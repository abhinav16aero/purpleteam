# docs/ — ADRs, runbooks, integration notes

The *plan* lives in `../plans/` (the authoritative `00`–`09`). This dir holds operational docs that
accrue as we build: architecture decision records (ADRs), bring-up runbooks, and the sovereignty/
evidence compliance notes.

- `adr/` — one file per significant decision (e.g. containerized-vs-host Ollama, multi-project compose)
- runbooks land here as each phase completes.

See `../plans/00_MASTER_PLAN.md` for the canonical decisions and the P0–P8 roadmap.
